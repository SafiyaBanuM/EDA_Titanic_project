# EDA_Titanic_project
#  Exploratory Data Analysis (EDA) on Titanic Dataset

##  Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic dataset to understand the data, identify patterns, detect missing values and outliers, analyze relationships between variables, and derive meaningful insights using statistical summaries and visualizations.

This project was completed as part of the **Thiranex Data Science Internship**.

---

##  Objectives
- Explore and understand the dataset
- Perform statistical analysis
- Identify missing and duplicate values
- Analyze data distributions
- Detect outliers
- Identify correlations among numerical features
- Generate visualizations to support data insights

---

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

---

##  Dataset
**Dataset Name:** Titanic Dataset

The dataset contains passenger information such as:
- Passenger Class
- Name
- Gender
- Age
- Fare
- Cabin
- Embarked
- Survival Status

---

## 📊 Exploratory Data Analysis Performed

### Data Inspection
- Displayed the first five records
- Checked dataset dimensions
- Examined data types
- Generated statistical summary
- Listed dataset columns

### Data Quality Checks
- Identified missing values
- Checked for duplicate records

### Visualizations
- Survival Count
- Passenger Class Distribution
- Gender Distribution
- Age Distribution
- Fare Distribution
- Age Box Plot
- Fare Box Plot
- Correlation Heatmap

### Correlation Analysis
- Computed correlation matrix
- Visualized feature relationships using a heatmap

---

##  Key Insights
- Missing values were found in the Age, Cabin, and Embarked columns.
- Most passengers traveled in Third Class.
- Male passengers outnumbered female passengers.
- More passengers did not survive than survived.
- Most passengers were between 20 and 40 years old.
- Fare values were right-skewed with several high-value outliers.
- Passenger Class and Fare showed relationships with survival.
